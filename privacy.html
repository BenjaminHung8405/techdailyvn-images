Privacy Policy — techdailyvn

Last updated: 14 November 2026.

techdailyvn is a personal tool operated by the owner of the TikTok account @techdailyvn. It uses the TikTok Login Kit and Content Posting API for one purpose only: to save a daily news carousel as a draft on the operator's own TikTok account.

Data used: the TikTok account's basic profile (open_id, display name, avatar) and the access/refresh tokens needed to call the API on the operator's behalf. Tokens are stored server-side and are never shared with any third party.

No personal data of any other person is collected, stored, or shared. No analytics, advertising, or tracking is used.

Contact: techdailyvn channel owner via TikTok @techdailyvn.
